## Context

Tokens live in `packages/ui-kit/tailwind/tokens/colors.ts` as one nested `colors` object, consumed by the Tailwind preset.
Stories are React Native, rendered by `apps/storybook`, which loads `packages/ui-kit/src/**/*.stories.?(ts|tsx)`.
`noArbitraryValues.test.ts` forbids `bg-[#...]` classes in kit sources, and dynamic class names would not be generated by Tailwind.

## Decisions

- **File:** `packages/ui-kit/src/Colors/Colors.stories.tsx`, covered by the existing stories glob. It follows "stories live next to their component" by living in its own folder.
- **Data:** import `colors` and flatten it recursively into `[path, value]` pairs, with path segments joined by `.`. Duplicates between a ramp step and a semantic alias are kept, because the alias name is what components use.
- **Sections:** one story per group, so each is a short scroll on a phone: `Palette` (the five ramps), `Surface`, `Text`, `Stroke`, `Overlays` (`outline` and `alpha`). Title `Foundations/Colors`.
- **Swatch:** a square whose fill is set with an inline `style={{ backgroundColor: value }}`, with the token name as a caption below it. The caption sits outside the swatch, so no per-color label contrast logic is needed.
- **Inline style exception:** the kit forbids inline `style` for token-covered values in components. A swatch must paint an arbitrary token value chosen at runtime, which no static class can express. The exception is limited to this story file and is stated in its header comment.
- **Checkerboard:** a small two-tone grid of views behind translucent swatches.
- **Not shown:** hex values, per the request.

**Rejected alternatives:**

- Hand-written list of swatches: drifts from the theme.
- Tailwind classes built per token (`bg-${name}`): violates the static class rule and Tailwind would not generate them.
- Hex label on each swatch: not requested; the name is the lookup key.
- One story with every group: a very long scroll on a phone.

## Risks

- The story adds `style` usage the kit otherwise avoids. Mitigated by keeping it in one story file with an explanatory comment.
- `noArbitraryValues.test.ts` scans non-test `.ts`/`.tsx` under `src`; the story must contain no bracketed class values.
