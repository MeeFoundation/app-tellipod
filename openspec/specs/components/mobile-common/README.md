# mobile-common

Behavior shared by the iOS and Android apps.

| Group | Read when |
| --- | --- |
| [shell/](shell/README.md) | Changing launch, sign-in or the main navigation |
| [pods/](pods/README.md) | Changing anything the user does with a pod |

Each spec names the use cases it realizes under `Realizes:`. User-facing scenarios live in [behaviour/](../../behaviour/README.md); these specs hold the technical contract. Slice and module names are not fixed yet (see `apps/app-tellipod/README.md`, "Not decided yet").
